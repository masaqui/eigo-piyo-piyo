# 🐣 EigoPiyoPiyo

**英語のリスニング&シャドーイングに効く! ネイティブ発音可視化ツール**

英文を入力すると、ネイティブのアメリカ英語カジュアル発音を解析し、カタカナ読み・IPA発音記号・音声変化を色分けしたHTMLを生成する [Claude](https://claude.ai/) のスキルです。
リスニングで聞き取れない、シャドーイングがついていけない、そんなときにeigo-piyo-piyoをご活用ください。

## 特徴

- 🔤 **ふりがな方式** — 英文の上にカタカナ読みをルビで表示
- 🎨 **音声変化の色分け** — リンキング・アシミレーション・リダクション・フラッピング・ダークLを一目で識別
- 🔗 **連結発音はひとかたまり表示** — `at a`→「アッラ」、`have a`→「ハヴァ」のように、複数語にわたる音の連結はカタカナも1つにつなげて表示（単語間の不要な空白なし）
- 📏 **フレーズ区切り** — 自然な息継ぎ・ポーズの位置を縦線で表示
- 🎯 **ストレス＆アクセント表示** — 強調語は太字＆大きいカタカナ、弱形は小さく薄く、単語内のアクセント音節も色分け
- 🔡 **IPA表記** — 英文の下にアメリカ英語のIPA発音記号を表示
- 🙈 **カタカナ表示トグル** — ボタン一つでカタカナ表示のON/OFFを切り替えられるので、最終的には英文だけでも読めるか確認できる
- 🇯🇵 **日本語訳** — 各文に自然な会話調の翻訳

## 対応する音声変化

| 色 | 名称 | 説明 | 例 |
|---|---|---|---|
| 🟠 | リンキング | 語末の子音と次の語頭の母音がつながる | pick up → ピカップ |
| 🔴 | アシミレーション | 隣り合う音が混ざって変化する | Could you → クジュ |
| 🔵 | リダクション・Hドロッピング | 発音しない・消える | What → ワッ |
| 🟢 | フラッピング | t/d がラ行の音に変わる | water → ウォーラー |
| 🟢 | ダークL | L がオ/ウのような音になる | bottle → バロー |

## 使い方

1. 下記セットアップ方法でスキルを登録する
2. チャットで英文を入力し「発音を教えて」と伝える
3. 生成されたHTMLファイルをダウンロードして、ブラウザで開く

## セットアップ

### 方法①: Claude.ai Projects で使う場合

1. Claude.ai で新しい Project を作成
2. Project の Knowledge に `SKILL.md` と `OUTPUT_FORMAT.md` をアップロード
3. チャットで英文を入力して「発音を教えて」と送信

### 方法②: Claude Desktop / Claude.ai の Skills 機能で使う場合

1. このリポジトリの `eigo-piyo-piyo/` フォルダを `eigo-piyo-piyo.SKILL` という名前のZIPファイルにまとめる
   ```bash
   zip -r eigo-piyo-piyo.SKILL eigo-piyo-piyo/
   ```
2. Claude の Skills 設定画面から `eigo-piyo-piyo.SKILL` をライブラリに追加
3. チャットで英文を入力して「発音を教えて」と送信

## 開発について

このスキルは実際の音声を聞きながら発音ルールを継続的に検証・修正しており、現在も改善が続いています。`SKILL.md` には音声現象の判定ルールとセルフチェックリストをまとめています。「この単語の発音、ガイドと違う」と感じたら、ぜひ [Issues](https://github.com/masaqui/eigo-piyo-piyo/issues) で教えてください。
